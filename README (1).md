# FCMB Pensions: mobile app concept

A UI/UX concept and clickable prototype for a pension management app, designed for iPhone 16 (393 x 852).

**Concept design only.** All names, balances and transactions are fictional demo data. This is not an official FCMB product.

## View it
Open `index.html` in a browser, or use the live link (GitHub Pages) shared with this project.

- **Design tab:** style guide plus all 10 screens as frames, with prototype flow arrows.
- **Prototype tab:** click through the app like a real user.

## Screens
Splash, Onboarding, Login, Account activation, Home dashboard, RSA details, Contributions, Growth, Profile and settings, Help and support.

## Built with
React 18, Tailwind CSS, htm. Fonts: Fraunces and Plus Jakarta Sans (Fraunces stands in for PP Eiko).
